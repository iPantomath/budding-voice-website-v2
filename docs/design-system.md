# Budding Voice Website Design System (Version 1.0)

> Project: Budding Voice Official Website
>
> Purpose: Define the visual identity, UI components, layout rules and interaction guidelines for the Budding Voice website.

---

# Design Philosophy

The website should communicate:

- Confidence
- Warmth
- Growth
- Professionalism
- Modern Education
- Human Connection

Visitors should feel:

> "These people genuinely care about helping children grow."

Avoid looking like:

- Tuition Centre
- Kindergarten
- Corporate Consultancy
- Government Website
- Generic Template

The website should feel like a premium education brand.

# Golden Rule

Every design decision should reinforce one message:

> Budding Voice is a trusted Communication & Leadership Centre that helps learners discover their voice, build confidence and grow with purpose.

When in doubt:

Choose simplicity over decoration.

Choose authenticity over perfection.

Choose clarity over complexity.
