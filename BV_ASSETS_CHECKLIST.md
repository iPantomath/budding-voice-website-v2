## PHASE 4 — About Page + Visual Assets (STARTING NOW)

### 1. About Page Content

The About page requires the following approved content:

- [ ] **Company Story** — Brief history/journey of Budding Voice (2–3 paragraphs)
  - How Budding Voice was founded
  - Why it exists
  - What makes it unique

- [ ] **Mission Statement** — Approved mission (1 sentence maximum)
  - *Suggested:* "To empower learners with communication, confidence and leadership skills that prepare them for life."

- [ ] **Vision Statement** — Approved vision (1 sentence maximum)
  - *Suggested:* "To nurture a generation of confident communicators who inspire positive change."

- [ ] **Core Values** — Descriptions for each of these 6 values (2–3 sentences each):
  1. Confidence
  2. Growth
  3. Integrity
  4. Respect
  5. Connection
  6. Leadership

- [ ] **Learning Philosophy** — Description of how learning happens at Budding Voice (2–3 paragraphs)
  - Experiential learning approach
  - Role of reflection, practice, facilitation, peer learning

### 2. Coach Information

Provide details for all coaches who will be featured on the website. Minimum 3 coaches required.

For each coach, provide:

| Field | Required | Format |
|-------|----------|--------|
| Full Name | ✅ Yes | Text |
| Role/Title | ✅ Yes | e.g., "Lead Coach", "Senior Facilitator" |
| Biography | ✅ Yes | 2–3 sentences about background, experience, approach |
| Specialisation | ✅ Yes | e.g., "Kaizen", "Orator", "APEX" or multiple |
| Professional Photo | ✅ Yes | Headshot, professional quality, 400x400px minimum |
| Email (optional) | ⭕ No | If they need direct contact |

**Example:**
```
Name: Alfred Chin
Role: Lead Coach – Kaizen Programme

Photo: [headshot file]
```

## HOW TO SUBMIT

Please provide assets and information as follows:

### **Format Guidelines**
- **Text Content:** Google Docs, Word, or plain text (copy-paste into email)
- **Images:** JPG/PNG files, organized in folders by category
- **Videos:** MP4 files, uploaded to shared drive or sent via WeTransfer
- **Multiple Items:** ZIP file or Google Drive folder with clear naming

### **File Naming Convention**
```
coach-alfred-headshot.jpg
kaizen-activity-storytelling.jpg
testimonial-sarah-lim.txt
hero-video-final.mp4
```

### **Submission Checklist**
- [ ] All files clearly named
- [ ] Organized by category/phase
- [ ] Include notes on any constraints (e.g., permission, usage rights)
- [ ] Confirm image/video ownership and usage rights
